THE BOTTLENECK

Mengapa Koreksi Ujian Sekolah Masih Begitu Menyiksa?

📝 Kertas HVS Fotokopi Biasa
Bukan LJK pensil 2B standar. Siswa menyilang (X) dengan pulpen tinta hitam pada tabel bergaris, sehingga scanner OMR mesin konvensional tidak bisa membaca.
✍️ Nama Siswa Tulisan Tangan
Variasi tulisan tangan, singkatan nama (contoh: "A. Fadilatul"), dan coretan membuat OCR mentah sering salah mengenali identitas siswa.
📊 Template AnBuso yang Rumit
Guru harus menginput nilai ke puluhan kolom spreadsheet Excel AnBuso secara manual. Satu salah ketik bisa merusak analisis daya beda soal.
💥 Library XML Merusak Menu VBA
Pustaka Python biasa (seperti openpyxl murni) menghapus tombol navigasi VBA Shapes saat menyimpan ulang berkas AnBuso.

SYSTEM PIPELINE

Arsitektur End-to-End Pipeline

1. Akuisisi & Normalisasi (OpenCV)
Deteksi sudut kertas, koreksi rotasi (deskew), dan segmentasi dinamis area identitas & area tabel jawaban.
2. Dual Identity Verification (RapidOCR + Fuzzy)
Ekstraksi No Peserta angka & nama tulisan tangan, dicocokkan ke database kelas via Levenshtein Distance (Akurasi 100%).
3. OMR Grid & Ink Density Engine
Filter morfologi garis untuk membedah sel A–E, menghitung rasio piksel tinta, dan mendeteksi jawaban ganda/ambigu.
4. Native AnBuso COM Injektor (pywin32)
Mengontrol resmi engine Microsoft Excel di background untuk menginjeksi nilai sambil mempertahankan 100% tombol menu VBA.

CORE ALGORITHM

Deteksi Tanda Silang Tanpa Deep Learning Berat

Mengapa kami memilih Classical CV dibanding model YOLO/CNN 2GB?

⚡ Ultra-Cepat & Zero GPU
Proses OMR berjalan dalam <50ms per lembar di prosesor laptop standar tanpa membutuhkan GPU Nvidia terpisah.
📐 Morphological Filtering
Kernel horizontal (35x1) dan vertikal (1x35) mendeteksi 100% batas kotak tabel ujian secara matematis dan deterministik.
🔍 Ink Pixel Ratio Analysis
Huruf cetak memiliki densitas tinta 8–12%. Coretan pulpen silang melonjak ke 20–35%. Selisih signifikan ini menjadi basis keputusan yang kokoh.
⚠️ Anti-Double Mark Guard
Jika siswa mencoret 2 opsi, sistem otomatis menandai status AMBIGU dan memberi peringatan di UI untuk verifikasi guru.

EXCEL PRESERVATION

Menyelamatkan Tombol Menu VBA AnBuso

Masalah teknis terbesar di balik otomatisasi spreadsheet macro.

❌ Masalah dengan Library XML Biasa (openpyxl)
Tombol menu navigasi di AnBuso adalah objek Drawing Shapes (VML). Library openpyxl secara otomatis membuang objek shapes saat menyimpan ulang berkas, membuat menu di Excel hilang total!
✅ Solusi Kami: Microsoft Excel COM Engine (`pywin32`)
Python mengendalikan langsung Microsoft Excel resmi di background. Hasilnya: 19 tombol menu navigasi di tab Isian dan 4 tombol di tab Jawaban 100% tetap utuh sempurna, tanpa merusak satu rumus pun!
